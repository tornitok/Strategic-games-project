# Стратегическая игра

Движок текстовых стратегических игр для учебных занятий: команды принимают
решения за стороны конфликта, детерминированная модель считает последствия,
после игры проводится разбор.

Игра идёт на одной машине: команды по очереди садятся за компьютер, вводят
приказы и сдают ход. Ведущий закрывает раунд, модель считает, проектор
показывает публичную сводку.

## Разработка

```bash
python3 -m venv .venv
.venv/bin/pip install -e ".[dev]"
.venv/bin/pytest
.venv/bin/python -m sgame run
```

## Команды

- `python -m sgame run` — запустить приложение и открыть браузер
- `python -m sgame validate <файл>` — проверить сценарий, с номерами строк

Запускайте их именно через `python -m sgame` из корня проекта. Консольная
команда `sgame`, которую создаёт `pip install -e`, на Python 3.14 не работает:
этот интерпретатор не обрабатывает `.pth`-файлы, поэтому editable-установка не
добавляет проект в путь импорта. На обычную (не editable) установку и на
собранное приложение это не влияет.

## Сборка приложения для macOS

```bash
./packaging/собрать.sh
```

Результат — `dist/Стратегическая игра.zip`. Памятка для получателя лежит в
`packaging/ИНСТРУКЦИЯ.md`.

## Как устроено

- `sgame/core/` — ядро: схема сценария, выражения, восемь фаз раунда,
  детерминированная случайность. Ни файлов, ни сети, ни веба.
- `sgame/session/` — журнал партии: хранятся приказы, а состояние получается
  пересчётом. Отсюда откат раунда и воспроизводимость.
- `sgame/narrate/` — правила видимости и шаблонный текст сводок.
- `sgame/web/` — три экрана: пульт ведущего, экран команды, проектор.
- `sgame/scenarios/meridian.yaml` — эталонная игра «Кризис в Меридианском
  заливе»: 4 стороны, 14 действий, 7 событий.

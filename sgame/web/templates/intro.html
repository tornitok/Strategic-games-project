Как устроена игра

  • Раундов: {{ spec.meta.rounds }}.
  • Очки действий: {{ spec.meta.action_points }} за раунд на команду — это и есть весь ваш ход. Дорогое действие может стоить не одно очко.
  • Ходят все одновременно. Порядок, в котором команды садятся за компьютер, на результат не влияет. Приказы всех сторон разрешаются вместе.
  • Одно действие — один раз за раунд. Повторить то же самое дважды нельзя, если рядом с ним не сказано обратное.
    • {% if has_secrets %}
  • Часть действий тайные. Их не видно в общей сводке. Противник может не узнать, кто за ними стоит, — а может и узнать.
    • {% endif %} {% if has_counters %}
  • Некоторым ударам можно противодействовать. Если сторона в этом же раунде подготовилась, эффект удара будет сильно ослаблен.
    • {% endif %} {% if has_rumours %}
  • Слухи. В сводке появляются непроверенные сообщения о том, кто за чем стоит. Они бывают правдой и бывают ложью — и запустить слух может как обстановка, так и другая команда.
    • {% endif %} {% if deals %}
  • Дипломатия: {% for deal in deals %}{{ deal.title }}{% if not loop.last %}, {% endif %}{% endfor %}. Предложение, сделанное в этом раунде, рассматривается адресатом в следующем.
    • {% endif %}
  • Победа. Итог считается по вашим показателям в сравнении с другими сторонами плюс выполненные цели из вашего брифинга. Цели у всех разные, и чужих вы не знаете.
